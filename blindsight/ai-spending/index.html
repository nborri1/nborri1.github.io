What caching means for the bill

A PDF example. Ask an AI to summarize a PDF, then ask a second question. If the same document text stays in the conversation, caching lets the model reuse its earlier processing, much like a temporary memory. Reusing that work reduces computation. The reused tokens still count, but cache reads typically cost less.

Why agents matter. Agents call tools and work through multiple steps, repeatedly using the same instructions and documents. That creates more opportunities to reuse cached context as agentic consumption expands, as discussed in our working paper.

Reading the gap. Faster growth in tokens than spending is consistent with the lower cost of cached tokens. Changes in model mix and model prices also affect spending growth. These aggregate comparisons do not isolate how much of the gap caching explains.

Scope. Complete Monday–Sunday weeks, January 5–September 27, 2026. These are recorded totals on OpenRouter, whose users are a nonrandom, relatively sophisticated sample.

Reading the components. Cache reads are part of input tokens; reasoning is part of output tokens. Other input is total input less reported cache reads. A missing cache count is not evidence that no caching occurred. The three plotted components add to the recorded total.

Reading spending growth. Spending follows the working paper’s measure of charges through OpenRouter, indexed to January 5–11 = 1. It includes OpenRouter’s fees for requests using customers’ own provider keys, but excludes their separately recorded provider inference charges. Token counts include those requests. This is not a separate bill for cached tokens or an estimate of savings from caching. Changing prices, model mix and billing arrangements also affect the comparison.

Source: authors’ analysis of updated, licensed OpenRouter data. See our working paper for the measurement framework.
